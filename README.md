# WorkMatch

A small freelance-project marketplace built with Vue, Vite, and Express.

## Requirements

- Node.js 22 or newer
- npm

## Run locally

Install dependencies:

```bash
npm install
```

Start the Vue application and Express API:

```bash
npm run dev
```

Open <http://localhost:5173>. The API runs at <http://localhost:3000>.

## Other commands

```bash
npm run build  # Build the Vue application
npm start      # Start only the Express API
```
